Project Title:
AI-Powered Virtual Try-On and Size Recommendation System Using CAT-VTON

Actors:
1. User
2. Admin

User Features:
- Sign up
- Sign in
- Change password
- Upload 4 images
- Enter measurements
- Browse clothes
- Generate virtual try-on image
- Receive size recommendation
- Approve or reject result
- View try-on history

Admin Features:
- Sign in
- Change password
- Add clothes
- Edit clothes
- Delete/deactivate clothes
- View users
- View try-on results
- View approvals/rejections
- View statistics
